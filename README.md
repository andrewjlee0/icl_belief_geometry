# icl_belief_geometry

Code for the paper **"Large Language Models Develop Belief State Geometry In-Context"** (arXiv link forthcoming).

We prompt pretrained LLMs (Qwen 3.5 9B/4B, Llama 3.1 8B, Llama 3.2 3B, Gemma 4 E4B/E2B) with 20,000-token sequences sampled from hidden Markov models and show that the residual stream comes to linearly encode the Bayesian belief state over the HMM's hidden states — its geometry, its relation to next-token prediction, and its causal role under activation steering.

## What is (and is not) in this repository

- **Code**: every experiment script, the HMM machinery, and the analysis notebook.
- **Results**: not shipped. All experiment outputs (CSV/NPZ, ~26 GB total) are written to `results/`, which is gitignored. Every result is regenerable from the scripts below; per-model runs of a single experiment take on the order of one GPU-hour on an 80 GB-class card (the 9B model with a 20k context is the binding constraint).
- **Figures**: generated by `plots/analyze.ipynb`, whose committed outputs double as the public record of the results — the notebook renders on GitHub with all figures and printed statistics embedded.

## Setup

```bash
bash setup.sh          # torch (cu128 nightly), transformers, accelerate, numpy, pandas, scikit-learn, numba, tqdm
export HF_HOME=/workspace/hf_cache   # or wherever model weights should cache
export HF_TOKEN=hf_...               # required for the gated Llama models
```

Scripts are run from the repo root or their own directory (they insert the repo root on `sys.path`), take `--model` (HF id), `--device`, and `--output_dir`, and write per-model CSVs named `<experiment>_<model_key>.csv`.

## Experimental design (shared by all scripts)

`configs/hmm_configs.py` defines the HMM families — **Mess3**, **Arch**, **Wing**, **Strata** (10 parametrizations each), plus **Delay** (used only by the multi-step readout experiment) and **Spiral** (defined but excluded from all paper analyses). For each (family, parametrization, seed ∈ 0–9): sample a 20,000-token sequence, compute exact Bayesian beliefs, tokenize with single-letter token names, run the model once, and fit ordinary-least-squares probes (always with bias) from residual-stream activations to targets, training and evaluating on the late window (positions 15,000–20,000) where the model's predictions have converged.

## Repository layout

### `src/` — shared machinery

| File | Contents |
|---|---|
| `src/hmm/definitions.py` | Transition-matrix constructors for every family, plus their order-1 (bigram) and order-0 (unigram) reductions used as baselines. |
| `src/hmm/core.py` | Stationary distribution, sequence sampling, exact Bayesian belief recursion, emission matrix, next-token probabilities, k-suffix beliefs (numba-accelerated where available). |
| `src/metrics/probes.py` | OLS linear probes with bias (ones-column augmentation), fitting/prediction/R² helpers used by every experiment. |
| `src/metrics/kl.py` | KL divergence helpers. |
| `src/model_utils.py` | Model/tokenizer loading for the Qwen, Llama, and Gemma families, prompt construction, position matching between HMM tokens and model tokens, chunked activation extraction with KV caching, full-vocabulary KL computation. |

### `configs/`

| File | Contents |
|---|---|
| `hmm_configs.py` | The `HMMS` registry (constructors, parametrization grids, token names) and `REPRESENTATIVES` (the per-family main-text parametrization). |

### `experiments/linear_probes/` — probing, KL, and geometry

| File | What it does | Output |
|---|---|---|
| `run_r2.py` | Per-layer R² of probes act → belief for all 40 parametrizations, with shuffled-target and random-target controls, plus belief geometry (probe predictions) extracted at each parametrization's best layer. | `r2_<model>.csv`, `geom_<model>.npz` |
| `run_kl.py` | KL(HMM ‖ LLM) over the full vocabulary along the sequence, against order-1 and order-0 baselines. | `kl_<model>.csv` |
| `run_obsprob.py` | Per-layer R² for act → NTP and act → log-NTP alongside act → belief, plus the model-free baselines ntp → belief and log-ntp → belief. | `obsprob_<model>.csv` |
| `run_redr2.py` | R² for k-suffix beliefs (beliefs computed from only the last k tokens) probed from activations produced on real, order-1, and order-0 sequences. | `redr2_<model>.csv` |
| `run_within.py` | Cross-parametrization transfer within a family: probe from parametrization i's activations to parametrization j's beliefs on i's sequence, with the ground-truth belief-to-belief ceiling. | `cross_<model>.csv`, `gt_cross_<model>.csv` |
| `run_between.py` | Same design across families with matching state counts (Wing ↔ Strata). | `between_<model>.csv`, `gt_between_<model>.csv` |
| `run_bottleneck.py` | Belief-bottleneck test: act → decoded belief → log-NTP (linear and quadratic second stage) versus act → log-NTP directly, with the analytic ceiling from true beliefs. | `bottleneck_<model>.csv` |
| `regen_geom.py` | Regenerates `geom_<model>.npz` for all parametrizations from an existing `r2_<model>.csv` without recomputing R². | `geom_<model>.npz` |
| `run_geom_controls.py` | Geometry visualizations for the shuffle/random controls and an early-context probe, reproducing the published fitting protocols exactly. | control geometry NPZs |

Probe-protocol robustness (added for the NeurIPS reviewer exchange; results reported in the rebuttal/appendix):

| File | What it does | Output |
|---|---|---|
| `run_r2_split.py` | Re-runs the R² experiment with a temporally contiguous train/test split (first 20% train, last 80% test) instead of the published interleaved split, everything else identical. | `r2_split_<model>.csv` |
| `run_r2_dump.py` | One forward pass per (parametrization, seed); saves fp16 best-layer activations and beliefs so probe-protocol analyses can run CPU-only afterwards. | `acts_*.npz` archive |
| `fit_r2_dump.py` | On the dumped activations: published random split, contiguous split, contiguous train-size sweep, and cross-sequence evaluation, per (model, family, parametrization). | `r2_protocols.csv` |
| `fit_gapsweep.py` | Gap-protected contiguous train-size sweep — fixed last-2,000-position test set, train blocks ending ≥ 500 positions earlier — isolating train-coverage from temporal adjacency. | `gapsweep.csv` |
| `run_r2_cross.py` | Per-layer held-out-sequence probing with cyclic pairing (seed s trains, seed s+1 tests), batched over layers. | `r2_cross_<model>.csv` |
| `fit_cross.py` | Cyclic held-out-sequence probes on the dumped best-layer activations, at the published 1,000-position train size and at the full window. | `r2_crosscyc.csv` |
| `fit_subspace.py` | Probe weight-subspace stability: principal angles between probes fit on disjoint halves of one sequence versus across sequences, at matched train size. | `r2_probesub.csv` |
| `run_kldecomp.py` | Decomposes the converged full-vocabulary KL into the off-alphabet probability leak and the within-alphabet KL. | `kldecomp_<model>.csv` |

### `experiments/causal_interventions/` — steering and patching

| File | What it does | Output |
|---|---|---|
| `run_intervene.py` | The belief-subspace intervention suite (activation patching and steering with matched controls), measured by KL of the model's own next-token distribution to targets. | `intervene_<model>.csv` |
| `run_decode_shift.py` | Direction-of-causality probing: steer the belief subspace and decode NTP/log-NTP downstream with frozen probes, and the reciprocal (steer NTP/log-NTP, decode belief). | `decode_shift_<model>.csv` |
| `run_decode_destroy.py` | The steering/decodability experiment behind the paper's Section 6 heatmaps. Steers the belief subspace (or, with `--donor ntp_matched`, along the NTP-preserving ker(M) direction δ) at each layer over the last 5,000 positions, then decodes belief, NTP, log-NTP, and the δ-coordinate at every later layer, scoring clean, frozen (fit before steering), and retrained probes against both the original's and the target's values. | `decode_destroy_*_<model>.csv` |
| `run_delay.py` | Delay-process interventions with multi-step output readout: the kernel coordinate is behaviorally silent now but determines a later reveal token, so belief-vs-flipped-belief patches dissociate at the reveal. | `delay_<model>.csv` |
| `run_subspace_sim.py` | Principal-angle similarity between the learned belief, NTP, and log-NTP probe subspaces (read and write directions separately) — the containment result gating the reciprocal steering test. | `subspace_sim_<model>.csv` |
| `run_decode_shift_modal.py`, `run_decode_destroy_modal.py` | Modal launchers for the two scripts above (environment-specific: they assume the authors' Modal workspace and local paths). | per-family CSVs |

### Shell launchers (environment-specific)

`setup.sh` installs dependencies. `run_probes.sh`, `run_probes2.sh`, `run_probes3.sh`, `run_interventions.sh`, and `run_tuned_lens.sh` are the multi-GPU work-stealing launchers used on the authors' rented pods; they assume `/workspace/icl_belief_geometry` and a local GPU fleet, and are included as a record of how the full grids were run rather than as portable entry points. Individual experiment scripts run standalone.

## Reproducing the paper

1. `run_kl.py` per model → convergence of the model's next-token distribution to the HMM's (Section 3).
2. `run_r2.py` (+ `regen_geom.py`, `run_geom_controls.py`) → belief decodability across layers and the belief-simplex geometry, with controls (Section 4).
3. `run_within.py` / `run_between.py` / `run_redr2.py` / `run_obsprob.py` / `run_bottleneck.py` → transfer, finite-window baselines, and the belief/NTP relationship (Sections 4–5).
4. `run_decode_destroy.py --full_story` (per donor condition) and `run_intervene.py` → the steering results (Section 6).
5. The probe-protocol scripts → the split-robustness analyses in the appendix.
6. `plots/analyze.ipynb` → all figures from the resulting CSVs.
